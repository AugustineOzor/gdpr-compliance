## Project Brief

## About this repository

This repo is a structured, portfolio-style write-up of a GDPR compliance program: a realistic (fictional) case study walking through the full DPO workflow — asset/processing-activity mapping, risk identification, control design against GDPR articles, evidence collection, and the governing policy set — for a retailer handling personal data at scale across the EU.


## How to read this

Each page links to the next via the navigation bar at the bottom — Assets → Risk Register → Controls → Evidence → Policies — the same order a DPO would actually build this program: know what you're protecting, know what can go wrong, design controls for it, prove the controls work, then formalize it all in policy.

## Methodology at a glance

- **Risk format:** every risk follows `[Threat] exploits [Vulnerability] causing [Impact] to [Asset]`, not a vague concern
- **Controls:** specific, measurable, and testable — a named mechanism, not "ensure compliance"
- **Honesty over polish:** most controls and policies are rated Not Tested, Partially Effective, Draft, or Under Review — reflecting a program just standing up its GDPR posture, not one pretending to be finished
- **Standards referenced:** GDPR articles (e.g. `Art. 12`, `Art. 15`, `Art. 22`, `Art. 28`, `Art. 33`, `Art. 35`, `Art. 46`), ISO 27001 (e.g. `A.8.3`)
